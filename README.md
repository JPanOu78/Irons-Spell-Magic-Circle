# Iron's Spell Magic Circle

A purely **Client-Side** visual addon for **Iron's Spells 'n Spellbooks** on **NeoForge 1.21.1** that renders customizable arcane magic circles during spellcasting.

## ✨ Features
- **100% Client-Side (`Dist.CLIENT`):** Works on any singleplayer world or multiplayer server without needing to be installed on the server (`displayTest = "IGNORE_ALL_VERSION"`).
- **School-Specific Arcane Aesthetics:** Designed to render custom magic circle geometry, sigils, and shader/particle rings matched to each spell school in *Iron's Spells 'n Spellbooks*.
- **Client Configuration:** Customize magic circle scale, rotation speed, and opacity via `irons_magic_circle-client.toml`.

## 📦 Requirements
- **Minecraft:** `1.21.1`
- **Mod Loader:** `NeoForge 21.1.84+`
- **Required Dependency:** `Iron's Spells 'n Spellbooks`
